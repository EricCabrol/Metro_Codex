Reading the chart

Each dot represents one valid run. Boxes span the 25th–75th percentiles; the central line is the median. Whiskers extend to observations within 1.5 interquartile ranges. n is the number of measurements.

From filtered signals

Measurements use manually reviewed station-stop boundaries. Each window contributes independently. Missing, incomplete or no-deceleration windows are excluded. All directions and interstations are pooled by line; small samples remain visible.

Compare the same interstation run

Overlay complete runs on the same line and in the same direction. Each signal starts at its validated restart (t = 0); time is not stretched to match arrivals. Choose an interstation, hide curves with the checkboxes, or drag and scroll to zoom.
